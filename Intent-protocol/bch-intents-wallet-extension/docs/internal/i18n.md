# Translations

## How it works

- `src/lib/i18n/en.ts` is the source catalogue: a flat object of `'section.name': 'Text'`.
- `MessageKey` is `keyof typeof en`. Every other catalogue is typed `Record<MessageKey, string>`, so a missing translation does not compile.
- Components get `t` from `useT()` or `useSettings()` and call `t('send.balance', { amount, symbol })`. Placeholders are `{name}`.
- The language is a setting (`settings.language`). On first run it is taken from the browser if we ship that language.
- The extension's name and description in the browser's own UI come from `public/_locales/<locale>/messages.json`.

## Rules

1. **No user-visible string outside a catalogue.** That includes `aria-label`s and button text.
2. **Whole sentences.** Never assemble a sentence from fragments in code: word order differs between languages. Use a placeholder.
3. **Keys are named for where they are used**, not for what they say: `send.error.gas`, not `notEnoughGas`.
4. **Errors from `lib/` return a key**, not text, when they are shown inline (see `validateAddress`). Errors that are thrown and caught pass through `errorMessage()` and are English for now.

## Tests

`tests/unit/i18n.test.ts` checks that:

- every catalogue has exactly the English keys
- every translation has the same placeholders as its source
- no translation is empty
- every key is used somewhere in `src/` (so removed UI does not leave dead strings)

## Adding a language

1. Copy `en.ts` to `<code>.ts`, export it typed as `Catalogue`, and translate.
2. Add it to `CATALOGUES` in `i18n/index.ts`, to the `Language` type and `LANGUAGES` list in `lib/settings.ts`, and to the allowed values in `normalizeSettings`.
3. Extend `detectLanguage()` if the browser language should select it.
4. Add `public/_locales/<locale>/messages.json`.
5. Add it to the i18n unit test.

## Status

| Language | State |
|---|---|
| English | Source |
| 简体中文 | **Machine-drafted, not reviewed by a native speaker.** Terminology (求解者 for solver, 助记词 for recovery phrase, 跨链 for bridge) follows common wallet usage but needs a review before it is advertised. |

## Not translated

- Server-supplied text: the swap server's error sentences and quote warnings, and the relayer's failure reasons, are shown as they arrive (English).
- Thrown library errors, after `errorMessage()`.
- Network and token names.
- Relative times from `timeAgo()` ("5m ago") and dates from `toLocaleString()`, which follow the browser's locale rather than the wallet's setting.
